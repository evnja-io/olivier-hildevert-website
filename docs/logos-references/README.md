# Logos de la section « Références »

Logos prêts à envoyer dans la médiathèque Strapi (champ `logo` de chaque entreprise,
page d'accueil → Références). **Uniquement avec l'accord écrit de l'entreprise** :
sans accord, laisser le champ vide — le site affiche alors le nom seul.

Format commun : PNG 800×320 transparent, monochrome (teinte `--color-mute`),
poids optique équilibré. Générés par `scripts/preparer-logos.mjs` :

```sh
node scripts/preparer-logos.mjs docs/logos-references chemin/vers/nouveau-logo.svg
```

Le nom du fichier source donne le nom du PNG. Partir du SVG officiel de préférence.
